# Explore the results

- Open `dashboard.html` in a browser to filter revenue and retention by month and acquisition channel.
- Open `retention.sqlite` in DB Browser for SQLite to run your own queries.
- Use `monthly_kpi.csv`, `cohorts.csv`, `collections.csv`, and `first_churn_risk.csv` for spreadsheet analysis.

Currency columns in the database and CSVs use paise. Divide by 100 for rupees.
